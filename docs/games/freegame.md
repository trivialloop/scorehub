# Free Game

- **Players**: 1–10 (equipment: any — cards, dice, or board box).
- Not round/turn-structured like the other games: any player can add/subtract points at any time via ± buttons (1/2/5). A round is "pending" for 3 seconds after the last button press for that player, then auto-commits; pressing a button for a different player commits the previous pending round immediately.
- Rounds are numbered globally (shared counter across all players), not per-player.
- The last committed round (when no round is currently pending) can be tapped to undo it and restore it as pending.
- No fixed win condition — this is a free-form score tracker; the user quits manually.
