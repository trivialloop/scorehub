# Wingspan

- **Players**: 2–5 (equipment: board box).
- One-shot grid (no rounds): all category rows colored per row once all players have entered scores.
- Categories: 3 bird habitats (Forest/Grassland/Wetland) + birds subtotal, Bonus cards, End-of-round goals, Eggs, Food on cards, Tucked cards.
- Highest total = winner.
