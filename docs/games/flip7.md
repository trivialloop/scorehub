# Flip 7

- **Players**: 3–10 (equipment: board box).
- Turn-based, one active player at a time; first player rotates each round.
- Scoring per turn: sum selected card values (0–12, up to 7 cards) → ×2 if the x2 bonus is selected → +15 if exactly 7 cards were selected ("Flip 7!") → + any flat bonus cards. Choosing 0 scores 0 for the turn.
- Score limit: **200 pts**, checked at the end of a full round (once every player has taken a turn that round).
